# Music Player App 🎵

A beautiful, feature-rich offline music player for Android with neumorphism UI design.

## Features ✨

- **Offline Playback**: Play music stored on your device
- **Playlist Management**: Create, edit, and organize playlists
- **Search**: Quick search through your music library
- **Queue Management**: Manage and reorder playback queue
- **Playback Controls**: Play, pause, next, previous, shuffle, repeat
- **Favorites**: Mark songs as favorites for quick access
- **Sleep Timer**: Auto-stop playback after set duration
- **Seekbar**: Jump to any position in a song
- **Background Playback**: Continue playing with screen off
- **Neumorphism Design**: Modern, elegant UI with soft shadows
- **Dark Theme**: Full dark mode support
- **Recent Songs**: Quick access to recently played tracks
